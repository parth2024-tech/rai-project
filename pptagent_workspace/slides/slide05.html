End-to-End Decision Flow Architecture

Candidate Intake → Dense Retrieval → Persona Deliberation → Moderator Synthesis → Graph Check → Cognitive Gate.

1. INTAKE

Candidate profile ingestion: skills, target role, monthly budget, timeline.

2. RETRIEVAL

ChromaDB retrieves top-4 ACM CS2023 syllabi and O*NET standards.

3. TRIAD

Planner (milestones), Critic (math gaps), Ethics (debt/bias audit).

4. SYNTHESIS

Moderator resolves disputes, builds Dispute Tree, calculates U_cal.

5. GRAPH CHECK

Deterministic 42-node DAG checks prerequisite order in < 0.2 ms.

6. HUMAN GATE

Blocks release if U ≥ 0.45 or Delta ≥ 1; activates Streamlit sliders.

ARCHITECTURAL SAFETY & SEPARATION OF POWERS
  • Separation of Powers: Advisory reasoning is strictly divided into non-deterministic semantic generation (LLM triad) and deterministic structural verification (external graph traversal).
  • Local Edge Execution: Entire pipeline executes locally on consumer hardware via local Qwen 2.5 7B (q4_k_m), guaranteeing complete student privacy and ₹0.00 cloud API expenditure.
  • Human Override Loop: Interactive Streamlit interface allows students to inspect the Dispute Tree and override pedagogical trade-offs via Speed vs. Rigor vs. Budget sliders.
